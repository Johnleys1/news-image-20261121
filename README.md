THE WORLD — one newspaper front page summing up Saturday 21 November 2026: 38 dated stories across 7 regions, from COP31 running into overtime in Antalya to three Houthi missiles shot down over Riyadh and a magnitude 6.7 earthquake in central Peru. Every story happened, or was first reported, on that day; sources are named beside each story, and a DATE CHECK box names what was deliberately left out because it belongs to an earlier day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the bundled `entry.png` (1024×1024) to the output directory. `draw.py` is the generator that drew the front page from the verified facts; `main.py` is the entry program (standard library only, deterministic).
